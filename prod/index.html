    two-wheel-exp¶

    A Gymnasium environment and a DeePC controller for a kinematic unicycle robot navigating to a goal in continuous 2D — plus the decision log behind both.

    The repo started as an attempt to port the data-driven predictive controller from Pai, Shang, Qian, Zheng (arXiv:2603.07395) into a clean Gym env for benchmarking against RL baselines. The story turned out to be more interesting than the destination: action-bound choices, cold-start lock-in, and bilinear dynamics that forced library switching all show up in the Journey.

    At a glance¶

    • System: discrete-time kinematic unicycle, Δt = 0.025 s, wall-clipped to a [-10, 10]² workspace.
    • Task: goal-reaching. Random start, random goal each episode. Terminate on ‖p − g‖ < 0.5 or truncate at 200 steps.
    • Action: (v, w) in physical units. Broad defaults v ∈ [0, 20], w ∈ [-π/2, π/2]; paper-faithful bounds are a CLI flag.
    • DeePC: hybrid L1 / L2 regularization following arXiv:2603.07395. Four orientation-keyed libraries for local linearization.
